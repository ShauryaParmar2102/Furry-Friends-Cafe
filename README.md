# 🐾 Furry Friends Café

### 🐶 A Responsive Pet-Friendly Café Website

Furry Friends Café is a multi-page website for a fictional pet-friendly café where visitors can explore food and drinks, discover dogs available for adoption, browse a photo gallery, and learn about birthday party packages.

I originally developed this website while studying my **Certificate III in Information Technology**. I later revisited the project during my Diploma studies to improve the layout, styling, navigation, responsiveness, and overall user experience.

## 🚀 Features

- 🏠 **Home Page** – Introduction to Furry Friends Café, with café information and images.
- 📞 **Contact Us** – Contact information, staff profiles, and an employment application form interface.
- 🍔 **Food Menu** – Breakfast, lunch, dinner, drinks, kids' meals, and dog-friendly treats with prices.
- 🐕 **Adoption Process** – Profiles of dogs available for adoption, including photographs and adoption information.
- 🖼️ **Gallery** – A collection of photographs featuring dogs that have visited the café.
- 🎉 **Party Bookings** – Three party packages with pricing, features, and enquiry links.
- 📱 **Responsive Design** – Layouts that adapt to desktop, tablet, and mobile screens.
- ☰ **Hamburger Navigation** – Interactive mobile navigation using JavaScript.

## 🎨 Website Improvements

This project was originally a basic website with large amounts of text and limited styling.

I revisited the website to modernise its appearance and improve the user experience.

### ✨ Improvements Made

- ✅ Improved the overall layout and organisation of content across all six pages.
- ✅ Replaced text-heavy sections with structured cards and grids.
- ✅ Improved spacing, alignment, typography, colours, and borders.
- ✅ Redesigned the food menu with individual item cards and prices.
- ✅ Improved the dog adoption page with organised profiles and photographs.
- ✅ Improved the layout of the party booking packages.
- ✅ Added responsive layouts using CSS Grid, Flexbox, and media queries.
- ✅ Added a JavaScript hamburger menu for mobile navigation.
- ✅ Improved image sizing to reduce stretching and cropping.
- ✅ Separated HTML, CSS, and JavaScript into dedicated files.
- ✅ Fixed navigation links and other layout issues.

These improvements helped transform the original text-heavy website into a more organised, responsive, and visually appealing project.

## 💻 Running the Website Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser or use the Live Server extension.
4. Navigate through the website using the navigation bar.

No additional installation or database configuration is required.
